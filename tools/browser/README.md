# Educational mapping visualizations

Open [NHWC.html](NHWC.html), [NCHW.html](NCHW.html), [explicit_simulator.html](explicit_simulator.html) or [im2collette_simulator.html](im2collette_simulator.html) directly in a browser; no server or dependencies are required. The files retain original contents and credits from im2col-comparisons.

These are historical educational models of mappings and tiling, not cycle-accurate models of the address-counter RTL. They do not validate initializer latency, native netlist behavior, power or the final two-packet prefetch implementation. Some visualization defaults and buffering details differ from this repository's RTL. Use the [implementation runners](../../README.md) and [systematic cycles](../cycles/README.md) for actual results.
